# Salma Mustefa - Video Editor Portfolio

A modern, high-impact cinematic video editing portfolio featuring interactive 3D flashcards with a custom liquid glass water effect and dynamic animated ambient lighting.

## 🚀 Live Demo & Features
- **Interactive 3D Flashcards**: Flip cards to explore featured project showcases.
- **Glass Water Effect**: Translucent refractive glass styling with surface highlights and hover sheens.
- **Dynamic Fluid Background**: Smooth organic floating orbs and ambient gradients.
- **Featured Projects**:
  - Immersive Headphones (Product Spotlight)
  - Saudi National Day (Cultural / Event)
  - AI App Collection (Tech & Software)
  - E-SIM Explainer (Telecom / Explainer)

## 🛠️ Tech Stack
- HTML5 & CSS3
- Tailwind CSS
- Vanilla JavaScript for 3D card flipping

## 💻 Local Development
Simply open `index.html` in your browser or run:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
